Privacy

How this static website handles calculator inputs and visits.

Calculator inputs

Calculations run in your browser. This version does not send your entered figures to us, save them in browser storage, or create a user account. Refreshing or resetting clears edits unless values are included in the page’s query string. Worked-scenario links include public example inputs in their URLs.

Hosting and ordinary requests

The site is hosted using GitHub Pages. The hosting provider receives ordinary request information, which can include an IP address, browser details, requested URL and time. Its processing is described in GitHub’s privacy statement. A URL containing query values may be stored in browser history or hosting logs; avoid putting sensitive information in shared URLs.

Cookies and tracking

This site’s own code sets no cookies and installs no analytics, advertising pixels or affiliate tracking. There are no external fonts or embedded media in V1. External links lead to services with their own privacy policies.

Contact

The public issue tracker is operated by GitHub and follows its account and privacy rules. Do not send sensitive financial information there. Any future analytics or private contact form requires this notice to be reviewed before activation.
