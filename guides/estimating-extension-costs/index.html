How to estimate the cost of extending a house

An extension budget needs a scope, quotes and a contingency before a financial comparison becomes meaningful.

Define the finished project

Include design, structural advice, permissions, building work, VAT, finishes and external work. A shell quote and a finished-room quote are not comparable. Add temporary accommodation and storage if needed.

Keep cost and value separate

The move-versus-extend tool asks for both the total budget and the estimated value added. A £60,000 project might add less or more than £60,000; do not assume they cancel. Ask for evidence from comparable local sales and valuations.

Stress the project

Increase the contingency and reduce the value added to see how sensitive the result is. Our V1 model finances all work through repayment borrowing at the entered rate. Staged drawdowns, unsecured loans and a lengthy construction period require a more detailed budget.
