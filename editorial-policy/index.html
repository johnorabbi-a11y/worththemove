Editorial policy

Clear assumptions, traceable sources and corrections without invented expertise.

What gets published

Each calculator answers a defined comparison. Each scenario contains calculated examples and specific assumptions. We do not publish arbitrary combinations of prices or rates just to create search pages.

Evidence and checking

The shared engine is checked against independent repayment examples and mathematical invariants. Supporting guidance is linked to official or public-interest sources where it discusses changeable rules. A code test is not a professional financial review; we do not present it as one.

Source records show the rule affected and the date a page was checked, where available. Build dates identify a content version rather than claiming ongoing monitoring. Tax figures and product restrictions are not assumed to be universal.

Corrections

Report a reproducible issue through our contact route, including the calculator and non-sensitive sample inputs. Corrections should update the shared model or source record first, regenerate affected pages, and run the checks. The public commit history records changes.

Commercial independence

There are no commercial placements in V1. If introduced later, each placement must carry a visible disclosure and must not determine the calculation result or be presented as a recommendation.
